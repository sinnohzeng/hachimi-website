# Spec 009：手机端首屏性能

> 造什么与为什么，不碰技术实现。
> 状态：已落地｜创建：2026-10-04

## 为什么

手机端 Lighthouse 性能分本地构建 `/zh` 81、`/en` 69，现网 `/zh` 64 到 73。LCP 元素是首屏那张起卦结果截图，TBT 全部来自道长的 Rive 运行时：装好后每帧在主线程上走十几毫秒，按手机档的四倍 CPU 折算，每一帧都是长任务。

## 造什么

- 首屏截图按显示宽度取图，出 AVIF，WebP 兜底；浅深两版、五张截图一起换，像素内容不变。
- Geist 正文字体只留拉丁段，等宽字体只留数字，等宽不预载；中文照旧走系统字体。
- 道长的 Rive 运行时等页面 load 之后、访客第一次动（指针、触摸、滚轮、滚动或按键）才取；之前由同一张脸的静帧顶着。暗色下不取浅色静帧，浅色下不取暗色静帧。

### 验收标准

1. GIVEN 本地静态构建、Lighthouse 13 手机档三次取中位数，THEN `/zh` 性能 ≥ 90，CLS ≤ 0.1，无障碍分不低于改动前。
2. GIVEN 手机视口浅色与深色，THEN 首屏版面、截图与道长静帧与改动前一致；滚一下之后道长动起来。
3. GIVEN `npm run check`，THEN 全绿。

### 不做

- 文案、节结构与视觉不动。
- motion 与 React 的首屏脚本量不动，LCP 剩下的差距记在 plan 里。
