# Spec 006：官网改成单页，文案对命理师与命理爱好者并列

> 造什么与为什么，不碰技术实现。
> 状态：已落地｜创建：2026-10-02｜上游：[005](../005-site-v4-tools/spec.md) 的七节结构与字数门｜客户定义：hachimi-ios ADR-0059

## 为什么

owner 2026-10-02 北京时间 13:34 看过线上官网，提了三条：

1. 官网只提“职业命理师”“专业命理师”，把命理爱好者排除在外了，相关文案都要改；“一位客户，一份命例”这类只提客户的句子也一样，命理爱好者在里面没有位置。
2. 排盘的规矩本身东西不多，没必要单独一页，整个官网改成单页。
3. 命例走查里手机换屏是从下往上推，App 里切这几屏并不是上滑，改成渐变一类的过渡。

客户定义随之改为命理师与命理爱好者并列，按做的事来定义：给人看盘、为人起卦的人。命理师给客户看，爱好者给自己、家人和朋友看。

## 站位

读者第一位是给客户看盘的命理师，与给自己和亲友排盘、在学紫微八字的命理爱好者，他们拿首页判断要不要装；第二位是慌了想起一卦的访客，与从商店跳回来确认的人。说话的是产品方，讲工具能做什么。媒介是网页扫读，中英双语。第二受众是应用商店与公众，按更严的一头定口吻。

## 造什么

### 称呼

- 首屏下第一句同时点到命理师与命理爱好者，中文与两家商店描述的首句同一说法；英文商店首句多一个 serious，下一趟版本列车跟官网改齐。
- 其余位置不拿“客户”“职业”“专业命理师”作唯一称呼。命例的主人写“这个人”“这位”，问事写“为谁问”；需要画面的那一句把客户、亲友与自己写在一起。

### 节表

首页七节与节序不变：首屏、定位（`#what`）、命例走查（`#case`）、四件工具（`#tools`）、学堂（`#academy`）、常见问题（`#faq`）、收尾（`#download`）。

排盘的规矩一页撤掉。它的七条按“一条论述一个位置”落到首页：

| 原条目                                       | 去向                                                             |
| -------------------------------------------- | ---------------------------------------------------------------- |
| 真太阳时                                     | 常见问题“真太阳时怎么算？”，原已在                               |
| 历法：夏令时、闰月、晚子时、换节气在盘上标出 | 并进同一条答案                                                   |
| 三种盘式                                     | 常见问题“三种盘式怎么切？”，原已在                               |
| 看格局                                       | 紫微斗数卡展开，原已在                                           |
| 安星派别与安星码                             | 紫微斗数卡卡面，原已在                                           |
| 八字四柱表与六柱细盘                         | 定位第三件与八字排盘卡展开，原已在                               |
| 更多排法                                     | 紫占与四柱反查的入口写进两张卡的展开；文本命盘与截图分享不上首页 |

常见问题加一条给刚开始学的人：词条、学堂与解读。

### 导航与网址

- 导航四项全是首页锚点：命例、工具、学堂、常见问题，右侧仍是下载。页脚“产品”一栏同这四项。
- `/{locale}/methodology` 永久转到对应语言首页的常见问题，裸路径 `/methodology` 与其他裸路径一样临时转到英文首页的常见问题；sitemap、`llms.txt`、`llms-full.txt` 与 `pageDates` 去掉这一页。
- 隐私政策、使用条款、删除数据、支持与帮助、下载落地页仍是独立页：两家商店后台登记的是这几个网址。

### 换屏

桌面端钉住的手机换屏改为原地交叉渐变：新一屏在上层淡入，下层那屏不动，屏幕不再有上下位移；往回滚时倒着淡出，不露出机身底色。左侧文字跟着换屏淡入淡出，位移收小。窄屏与减弱动态那一档本来就只有一张手机，不变。

### 验收标准

1. GIVEN `lib/i18n/zh.ts` 与 `en.ts`，THEN 不出现“职业命理师”“专业命理师”“professional”；“客户”与 “client” 各只出现在客户与亲友并列的那一句。
2. GIVEN `/zh` 与 `/en`，THEN 导航与页脚“产品”栏的链接全是本页锚点；`out/` 里没有 methodology 页；线上 `/zh/methodology`、`/en/methodology/`、`/methodology` 都转到首页的 `#faq`。
3. GIVEN 桌面 1440 宽从上往下滚过命例走查，THEN 五屏依次原地渐变，没有上推；往回滚倒着渐变，过程中不露出机身底色。
4. GIVEN 字数门，THEN 全绿；常见问题每条答案不超过 70 字，英文不超过 42 词。
5. GIVEN 浏览器实拍桌面 1440 与手机 390、中英、浅深，THEN 无横向溢出，导航四项点击都落到对应节。
6. `npm run check` 全绿，推 main 上线后回读线上。

### 不做

- 首屏口号、节结构与各节视觉不动。
- 不给排盘的规矩在首页另开一节。
- 两家商店的描述与 App 内字串这次不动：两端 2.0.0 都在审，下一版按 ADR-0059 改。
