# Spec 005：官网第四版，按“学习与研究中国民俗术数的工具”重排

> 造什么与为什么，不碰技术实现。
> 状态：Draft｜创建：2026-09-22｜上游：[004](../004-positioning-and-footer/spec.md) 的定位口径、[003](../003-orb-on-rive/spec.md) 的圆球宿主｜取代：[001](../001-site-v3-concise/spec.md) 的七节结构与字数上限

## 为什么

owner 2026-09-22 定：App 的功能与定位比第三版（2026-09-14）时变了很多，官网可以大幅重构，无历史包袱；参考本机模板包 reactbits-pro-templates 做得“炫酷优雅”；改版前先看改版前的历史版本有没有值得拿回来的。

四路调研（`docs/research/2026-09-22-site-v4-research.md`）的结论：

- 第三版把排盘深度藏进二级页的前提是“品牌调性接近陪伴类 App，硬术语不上首页”。定位改成面向命理爱好者与职业命理师的工具之后，同一份十六站调研对 iztro 的判词反过来适用：受众懂行，术语可以放前面。第二版被砍的命盘机制事实、排盘 FAQ、三盘扇形是最该翻回来的素材；一句话首屏、不编社会证明、单一 CTA、FAQ 第一条直答“是不是算命”、不做 bullet 墙，这几条与定位无关，仍成立。
- 改版前历史里值得拿回来的：第二版命盘深讲的机制事实（已核过出处）、排盘 FAQ 七条、桌面三盘扇形、Showcase 横滑版式、“底下四格”按 App 信息架构讲产品、方法论页整套；第一版 b 的场景卡与“墨与金”线稿卡是次级素材。不要的：机制头牌与客服腔、首屏叠文字、bullet 墙、统计条、社会证明、安卓现在时、英文页装饰汉字、点名供应商。
- 模板库十套全是 Next 16 加 Tailwind v4 加 motion，与本仓同栈。最适配的三套：ai-app（唯一的手机 App 落地页，钉住的手机走查）、shader（ogl 光束 shader，比现有 three.js 轻）、wireframe（细线框与点阵，本仓页脚已在手写同一套语言）。只新增 ogl 一个依赖，three 摘掉；GSAP、R3F、drei、postprocessing 一概不引。
- App 此刻（1.13.0）的核心事实：命例是全 App 的枢纽身份，一条命例四面（八字、紫微、亲密、问事）；卦表以 caseId 挂在命例上，命例详情的问事面按起卦时刻倒序列出名下每一卦，删命例连同名下的卦，导出导入与 iCloud 同步都带着卦。这就是“每份命例名下的卦追得回去”的实体。

## 站位

读者第一位是命理爱好者与职业命理师（搜“紫微斗数排盘 App”进来、拿着老命书要排盘、手上几十个命例要管的人），第二位是慌了想起一卦的普通访客与从商店跳回来确认的人。说话的是产品方，陈述工具能做什么与边界，不声称预测、不承诺改运。媒介是网页扫读，句子短，信息前置。第二受众是应用商店与公众，按更严的一头定口吻。

## 造什么

首页从“一句口号加七节短句”改成“一句口号加一条命例走查加四件工具”，深度按需展开；方法论页与法律页不动。

### 验收标准

1. GIVEN `/zh` 首屏，THEN 只有口号一句、猫、徽章与手机截图；口号原文不动；截图是一卦吉的结果页，浅深各一张。
2. GIVEN `#case` 一节，THEN 桌面端手机钉住、随滚动换五屏，每屏左侧一段文字；移动端退化成手机加有序步骤；开了减弱动态时只显示一张手机与步骤列表。五屏截图依次是命例列表、紫微三合盘、八字四柱页、起卦结果页、命例的问事面，全部来自 iOS 1.13.0 界面、署名合成命例。
3. GIVEN `#tools` 四张卡，THEN 卡面只有名字与一句；点开才见机制事实；每条事实在 `docs/research/2026-09-22-site-v4-research.md` 的 App 清单里有出处；不写内核未接的流日流时、不写安卓现在时、不写准确率。
4. GIVEN 全站，THEN 不引 three、GSAP、R3F；新增依赖只有 ogl；两处 shader 由同一个组件加两套调色板承担；减弱动态时 shader 只画一帧；离开视口与页面转后台停帧。
5. GIVEN 字数门，THEN 上限改成五档：首屏 9 字；给命理师那一节（一句加三件事）不超过 180 字；四张卡的卡面、道长记得、学堂、本机与收尾合计不超过 320 字；命例走查（标题、引言与五步）合计不超过 240 字；每张卡展开不超过 110 字；FAQ 每条不超过 70 字；英文 0.6 倍。键表随节表重写，机制保留。
6. GIVEN `public/llms.txt`、`llms-full.txt`、`site.webmanifest`、`README.md` 的描述，THEN 与 004 的定位同口径。
7. GIVEN 浏览器实拍桌面 1440 与手机 390、浅深、中英八张，THEN 无横向溢出、无空白节、首屏无累积布局偏移；Rive 猫与 shader 同屏时不掉帧到肉眼可见。
8. `npm run check` 全绿，推 main 上线，`curl` 六个法律 URL 与 `/zh` `/en` 全 200。

### 不做

- 首屏口号不动；不摆社会证明、评分、下载量、准确率。
- 不新增页面；方法论页只改导航标签，文案另立规约。
- 不引 GSAP、R3F、drei、postprocessing；不做全窗常驻的流体或点阵光标。
- 页脚不动（004 刚落地）。
- 学堂不加戏：一句加跑马灯，不放截图。
- 不做隐私遮罩式的截图打码：截图用合成命例，本来就没有真人。
