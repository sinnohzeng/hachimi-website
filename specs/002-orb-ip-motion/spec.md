# 猫 Orb 品牌与动作

Owner 于 2026-09-15 授权完整动作库、官网核心 IP、网站和 App 图标一起更新及上线。

产品规约真源位于 hachimi-ios 的 specs/062-orb-ip-motion。官网保留七节信息结构与首屏一句话，加入同一只原生猫 Orb。首屏使用 waking 一次、21 秒待机循环；页脚使用 43.8 秒循环。所有 35 种行为保存在动作模块中供按场景调用。

Owner 补充布局约束：Hero 中道长只在左侧文字区小尺寸出现；右侧保留 App 主要功能截图，不由人物替换。图标采用进一步放大并偏左下的同源 Orb。

## 实现与验收

- 几何、表情、行为参数与黄金帧由 iOS 的 scripts/export-orb-web.sh 导出；public/brand/orb-source.json 记录源码与产物哈希。禁止手改生成的 JSON。
- 客户端使用独立时钟和固定 1/120 秒步长；位移以球半径、角度以度为单位。JS 端用原生黄金帧逐项测试，避免两端悄悄画出不同的人物。
- 鼠标移动与点击相对 Orb 中心轻微跟随，x/y 钳位；触屏点击 1.5 秒后回正；事件被动监听，不阻止浏览器滚动与按钮。
- 减少动态、无 JS、WebGL 不可用时呈现同源静态图。后台与离开视口停钟，卸载释放 RAF、事件、观察器与 GPU 对象。
- favicon、Apple Touch、PWA 与 OG 图标从同一黑银母版生成；favicon 保留多尺寸 RGBA ICO，以适配 Next 图像解码。
- npm run check 包含新增动作与对拍测试。中英、手机与桌面、后台恢复、减少动态、位置交互和生产域均需验证。

## 实施顺序

1. 导出原生资产与黄金帧，先写失败的 JS 对拍测试。
2. 移植行为调度与几何投影，用黄金帧校验；接入现有 hero/footer。
3. 替换图标并检查静态回退和小尺寸辨识度。
4. 完整质量门、受控浏览器验收、Git 提交、Cloudflare 发布及生产验证。
