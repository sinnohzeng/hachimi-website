# Spec 004：定位口径、页脚精简与首屏球径

> 造什么与为什么，不碰技术实现。
> 状态：Landed｜创建：2026-09-22｜上游：[001](../001-site-v3-concise/spec.md) 的七节结构与字数门、[003](../003-orb-on-rive/spec.md) 的两处圆球位

## 为什么

owner 2026-09-22 看过换了新形象的官网后定了三件事。

1. 桌面端的猫显得偏大，移动端刚好。
2. 页脚那行统计（随包多少本古籍、0 个账号）没有意义。页脚“法律”一栏与页面底部那行隐私政策、使用条款、删除数据是同一组入口出现两次，按单一来源只留一处。
3. 收尾那句“把道长装进手机，慌时有处去”只说了起卦与陪伴。产品此刻的面貌是：梅花易数起卦与情绪陪伴之外，有紫微斗数与八字排盘；更核心的长处是多命例管理，以及每份命例名下起过的卦都追得回去，这对命理爱好者与职业命理师都是实打实的附加值；学堂是锦上添花。对外定位是学习与研究中国民俗术数的工具类、生活方式类 App，全站文案按这个口径调。

## 站位

读者是命理爱好者与职业命理师，也有慌了想起一卦的普通访客，他们拿这些句子判断这是什么、要不要装。说话的是产品方，陈述功能与边界，不声称预测、不承诺改运。媒介是网页扫读，一句一事。第二受众是应用商店与公众，按更严的一头定口吻。

## 造什么

### 验收标准

1. GIVEN 首屏在 lg 及以上，THEN 球径 96 px，与移动端同一档；页脚同为 96 px。
2. GIVEN 页脚，THEN 没有统计小字；栏目只剩“产品”与“联系”；隐私政策、使用条款、账号与你的数据、删除数据只在页面底部那一行出现一次；版权行并进底部那一行；道长与字标下面是一句定位语。
3. GIVEN 第二节标题，THEN 写明它是学习与研究中国民俗术数的 App，起卦、排盘、管命例三件事都在，猫道长仍在。
4. GIVEN 命盘一节，THEN 标题下一句讲多命例管理与每份命例名下的卦追得回去。
5. GIVEN 收尾那句，THEN 卦、盘、命例三件都在，仍以“把道长装进手机”起头。
6. GIVEN 常见问题第一条，THEN 先说它是学习与研究的工具、也供陪伴，再说不预测、不改命、不转运、不声称准。
7. GIVEN 站点描述（SEO 与 JSON-LD），THEN 与上面同一口径。
8. 字数门照 001 的上限走：统计那行退出计数，命盘那句进计数；页脚定位语与版权行同类，不计。英文对应句同步。

### 不做

- 首屏口号“慌的时候，先起一卦。”不动，owner 定的北极星。
- 学堂一节那句不动，学堂是锦上添花，不再加戏。
- 不新增“命例”专节：001 定的七节结构不动，命例的话放进命盘一节。

## 落地记录

2026-09-22 落地。桌面端球显大的原因：像素上桌面 112 px 只比移动端 96 px 大一成半，但桌面端球靠左、单独占一行，眼睛把它当标题上方的标识看，标识的惯例尺寸不超过标题字高；移动端球居中在标题上方，读作头像，头像放到标题两三倍高都正常。所以桌面收到与移动端同一档，不按视口再放大。
