# Spec 008：收费延后与“写给道长”在官网上的落点

> 造什么与为什么，不碰技术实现。
> 状态：进行中｜创建：2026-10-03｜上游：hachimi-ios ADR-0061、spec 114、spec 115｜上一版：[007](../007-copy-system/spec.md)

## 为什么

owner 2026-10-03：收费往后延，付费墙一律不建，先拿第一批用户的反馈；要一个方便整体收集的反馈途径。决定与理由在 hachimi-ios ADR-0061。官网跟着改三处：常见问题不再讲会员，支持页写上 App 里的反馈渠道，隐私政策补一条反馈。

## 造什么

- 常见问题撤下“会员管什么”，剩五条。定稿句 C6 已撤出定稿句表，`check:canon` 不再核它。
- 支持页开头一句讲两条渠道：App 里“我的 → 写给道长”寄一封，或者写邮件；要回复的写邮件。“联系我们”表加一行 App 内渠道，回复一栏写不回复、每一封都会看。
- 隐私政策随 hachimi-ios `docs/legal/` 同步，第二节多一条“反馈和举报”；`pageDates` 的隐私与支持两页改成同步当天。
- 常见问题与隐私政策现在就改；支持页等 2.1.0 两端上架当天再推，免得在架旧版的用户照着找不到入口。

### 验收标准

1. GIVEN `npm run check`，THEN 全绿，其中 `check:canon` 核四句（C1 至 C4）。
2. GIVEN `/zh` 与 `/en` 首页常见问题，THEN 五条，没有会员。
3. GIVEN 支持页中英，THEN 开头讲两条渠道，联系表两行。
4. GIVEN 隐私政策中英，THEN 第二节有反馈一条，与 hachimi-ios 真源逐字相同。
5. 推 main 上线后回读线上常见问题、支持页与隐私政策。

### 不做

- 使用条款里会员订阅那一节不动，那是开收之后的规矩。
- 节结构、节序与视觉不动。
